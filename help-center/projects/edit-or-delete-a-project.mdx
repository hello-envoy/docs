## What you'll accomplish

Edit project information or delete a project you no longer need.

## Open project details

Use either of these. They open the same **Project Details** form.

- On the wedding, click **Project**, then **Edit project details**.
- Under **Weddings** on the left, point at the wedding and click **Project details**.

## Edit project details

1. In **Project Details**, click **Edit**.
2. Change any fields — title, description, location, budget, or deadline.
3. Click **Save** or **Cancel**.

For **Location**, enter a ZIP code or full address and select a suggestion. A field that has not been added shows **Not set**.

<Tip>
  You can also ask Envoy to update these fields. A search area is not saved as the location. See [Update project details](/help-center/ask-envoy/update-project-details).
</Tip>

<Note>
  If you close **Project Details** with unsaved edits, Envoy asks you to confirm before discarding them.
</Note>

## Delete a project

Deleting a project is permanent.

1. Open **Project Details**.
2. Click **Edit**, then **Delete project**.
3. In the confirmation dialog (**Delete project?**), confirm by clicking **Delete project** again.

Once deleted, the project is removed from your dashboard and from **Weddings**.

<Warning>
  Deleting a project cannot be undone. Outreach threads and project-specific data associated with that project will no longer be accessible from Envoy.
</Warning>
