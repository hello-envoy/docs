## Account and sign-in

### I can't sign in with Google or Outlook

Envoy supports sign-in with **Continue with Google** or **Continue with Microsoft** only — there is no email-and-password option.

On registration, make sure you checked the mailbox authorization box before clicking the sign-in button.

If buttons are disabled, check the authorization checkbox on the [Create account](https://app.hello-envoy.com/register) page.

### I need to use a different Google or Outlook account

Click **Logout** in the sidebar, then sign in again and choose the correct account in the Google or Microsoft prompt.

On the consent page during registration, use **Sign out** in the header instead.

### I'm stuck on the consent page

You must accept the Terms of Service and acknowledge the Privacy Policy to continue. Use **Sign out** if you need to switch accounts.

## Contacts and search

### No search results on the homepage

Try a more specific project description first — vague inputs like *home project* or *fix something* may return no matches. Also verify your ZIP or postal code and click **Search again**.

### Search returned nothing for a vague description

Envoy matches contacts to the type of work you describe. Replace generic wording with specifics: *kitchen cabinet installation* instead of *home improvement*, or *150-guest outdoor wedding catering* instead of *event*.

### I see “Showing the first contacts we found”

The search ended early, and Envoy is showing the contacts it already found. The warning says **Showing the first contacts we found. Refine the description if you want more.**

Review those contacts, click **Retry**, or refine the description for a more focused search. On the homepage, update **What are you planning?** During project creation, click **Refine search**.

### The search connection ended, or I am offline

A longer search stays connected while Envoy is still looking, so it does not stop without a message.

If you see **The search connection ended before it finished. Retry, or refine the description for a more focused search.**, the search stopped before it finished. Click **Retry**, or refine the description and try again.

If you are offline, Envoy shows a different message so you can tell a lost connection from an interrupted search. Check your connection, then click **Retry**.

These messages are separate from **No matches found** and **No matches found for your search**. An empty result means the search finished and nothing matched your description or location. See [Find and add contacts](/help-center/contacts/find-and-add-contacts) and [Find contacts before signing up](/help-center/get-started/find-contacts-before-signing-up).

### My pre-signup contacts didn't carry over

Your anonymous search session may have expired. Start a new search on the homepage and select contacts again before registering.

### Contact missing email

Add an email address on the project **Overview** tab, during the onboarding wizard (**Additional contact details required**), or in **Contacts** before sending outreach.

## Projects

### I don't see my project in the sidebar

Only active projects appear in the sidebar list (up to 10). Open **Dashboard** to see recent projects.

### Unsaved changes warning

When editing on the **Overview** tab, save with **Save** before switching tabs or you'll be prompted to confirm.
