## What you'll accomplish

Ask Envoy, on the **Chat** tab, to suggest service providers for this project. You review the list before anyone is added.

To search from **Contacts**, a project **Overview**, or project creation instead, see [Find contacts](/help-center/contacts/find-contacts).

## Before you start

- An open project
- A ZIP code saved on the project, or a place you can name in your message

## Find service providers

1. Open the project and click the **Chat** tab.
2. Type the kind of help you need, such as *Find a wedding florist* or *Find a roofer near me*.
3. Press **Send**.

Envoy searches near your project location and suggests up to five contacts at a time. Each suggestion includes the name, category, and location. Envoy marks any contact that is already on the project.

Ask for more, for example *Show me more*, to see the next five. Envoy skips contacts it already suggested.

Envoy searches one type of service provider at a time, such as a florist, a caterer, or a venue. Ask again for each additional type.

When you know who you want, see [Add contacts from Chat](/help-center/ask-envoy/add-contacts).

## Search a different area

Name the area in the same message if you do not want the search to use the project location. You can share a ZIP code, a place such as *Charlotte, NC*, or a distance such as *within 30 miles*.

Envoy uses that area for this search only. It does not change the location saved on the project.

## If Envoy cannot search yet

Envoy needs a ZIP code on the project, or an area in your message, before it can search. If neither is set, Envoy asks you for one. Reply with the place, then ask for the search again.
