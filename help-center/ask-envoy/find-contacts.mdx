## What you'll accomplish

Ask Envoy, on the **Chat** tab, to suggest service providers for this project. The suggestions are not added yet. You name who to add in a later message.

To search from **Contacts**, a project **Overview**, or project creation instead, see [Find contacts](/help-center/contacts/find-contacts).

## Before you start

- An open project
- A ZIP code saved on the project, or a place you can name in your message

## Find service providers

1. Open the project and click the **Chat** tab.
2. Type the kind of help you need, such as *Find a wedding florist* or *Find a roofer near me*.
3. Press **Send**.

Envoy searches near your project location and suggests up to five contacts at a time. Each suggestion includes the name. Envoy can also include the place or website when it has them, and it marks any contact already on the project.

This message only offers options. A short *yes* does not add anyone. See [Add contacts from Chat](/help-center/ask-envoy/add-contacts) when you are ready to name who to add.

Ask for more, for example *Show me more*, to see the next five. Envoy skips contacts it already suggested. If there are no further matches, Envoy says it could not find additional options.

Envoy searches one type of service provider at a time, such as a florist, a caterer, or a venue. Ask again for each additional type.

## Search a different area

Name the area in the same message if you do not want the search to use the project location. You can share a ZIP code, a street address with a ZIP, a place such as *Charlotte, NC*, or a distance such as *within 30 miles*.

Envoy uses that area for this search only. It does not change the location saved on the project. To save a ZIP or street address on the project, see [Update project details](/help-center/ask-envoy/update-project-details).

## If Envoy cannot search yet

Envoy needs a ZIP code on the project, or an area in your message, before it can search. If neither is set, Envoy asks for a ZIP or a city and state. Reply with the place, then ask for the search again.

If the search does not finish, Envoy says so. Ask again in a moment.
