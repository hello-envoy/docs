## What you'll accomplish

Ask Envoy on the **Chat** tab to save project details you state. Saved details show on the **Overview** tab.

You can still edit the same fields on **Overview**. See [Edit or delete a project](/help-center/projects/edit-or-delete-a-project).

## Before you start

- An open project
- The **Chat** tab

## Save the details you state

1. Open the project and click the **Chat** tab.
2. State the details you want saved. You can include more than one in the same message, such as a budget and a street address.
3. Press **Send**.

Envoy saves each detail it understands. It does not ask you to restate a clear value.

You can update:

- **Title**, when you ask to rename the project
- **Description**
- **Location** — a ZIP code or a street address. A search area, such as *within an hour of downtown Dallas*, is not saved. Envoy asks for a ZIP or street address instead.
- **Deadline** — a date, or a phrase Envoy can put on the calendar, such as *the end of the year*
- **Budget** — an amount greater than zero, such as *10k* or *$10,000*

A place you name only so Envoy can find contacts does not change the location saved on the project. See [Find contacts with Envoy](/help-center/ask-envoy/find-contacts).

## If a detail is not saved

Envoy tells you it was not saved and asks for what it still needs. A budget of zero is not saved. Say an amount greater than zero if you want a budget on the project.

If one message gives two different places or two different times for the same event, Envoy does not save that message. It asks which facts to keep.
