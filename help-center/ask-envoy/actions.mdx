## What you'll accomplish

See the tasks you can ask Envoy to do for this project on the **Chat** tab, then open the guide for the one you need.

## Before you start

- An open project
- The **Chat** tab selected

Type your request in the message field and press **Send**. Envoy keeps the answer tied to this project.

## Actions

<CardGroup cols={2}>
  <Card title="Find contacts" icon="magnifying-glass" href="/help-center/ask-envoy/find-contacts">
    Ask Envoy to suggest service providers near your project, a few at a time.
  </Card>
  <Card title="Add contacts" icon="user-plus" href="/help-center/ask-envoy/add-contacts">
    Tell Envoy which suggested contacts to add to this project.
  </Card>
</CardGroup>

You can also plan the work, ask how a type of service provider usually quotes, and have Envoy prepare outreach drafts you still review. See [Plan with Envoy](/help-center/ask-envoy/chat-planning).

## Other ways to work with contacts

These **Contacts** guides stay on the Contacts pages. They are separate from asking in Chat:

- [Find contacts](/help-center/contacts/find-contacts) — search from **Contacts**, a project **Overview**, or project creation
- [Add or upload contacts](/help-center/contacts/add-or-upload-contacts) — enter a contact yourself, or import a file
